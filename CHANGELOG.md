# Changelog

## 0.1.3 — 2026-10-07

- Place static and shared native outputs in the NuGet target's expected directory so iOS consumers link the packaged C archive.

## 0.1.2 — 2026-10-07

- Add a serialized Go layout API over the pinned Clay core.
- Add the optional GoForge Cadence and Quicken Native adapter module, preserving native Gio controls and events while using Eclaire-computed geometry.
- Align GoForge adapter dependency version with the Eclaire release and its single Clay pin.

## 0.1.1

- Build target specific C libraries for .NET iOS and Android consumers, and link/package them through native build items.

## 0.1.0

Initial preview release.

- C ABI around Clay's frame layout and render command APIs.
- Version 1 semantic UI contract and IR schema.
- Matching C, F#, and Haskell browser showcases.
- CMake build and install package for native consumers.
